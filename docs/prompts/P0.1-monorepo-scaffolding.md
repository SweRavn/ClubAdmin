# P0.1 — Monorepo scaffolding

## Context
Read first: `CLAUDE.md`, `docs/architecture.md`, `docs/licensing.md`,
ADR 0002, ADR 0012.
What exists already: documentation only. No code.

## Goal
A clean clone can run `pnpm install && pnpm lint && pnpm typecheck && pnpm test
&& pnpm licenses:check` successfully, and CI on GitHub runs the same checks on
every push to `main` and every PR. All later packages plug into this skeleton.

## Scope

### Workspace
- Root `package.json` with `packageManager` (pnpm, via Corepack) and
  `engines.node` set to the current Node.js LTS; `.nvmrc` with the same version.
- `pnpm-workspace.yaml` covering `apps/*`, `packages/*`.
- `.npmrc` / pnpm settings: lifecycle scripts **disabled by default**, with an
  explicit `onlyBuiltDependencies` allow list (empty for now); strict peer deps;
  `minimumReleaseAge` (or equivalent) so freshly published versions are not
  installed immediately.
- Turborepo `turbo.json` with tasks `build`, `dev`, `lint`, `typecheck`, `test`,
  `test:integration`, `test:e2e`, with correct caching and dependencies.
- Placeholder packages (each with `package.json`, `tsconfig.json`,
  `src/index.ts` exporting nothing yet, and one trivial test):
  `apps/api`, `apps/worker`, `apps/web`, `apps/mobile` (folder + README only;
  the Expo app is created in P0.10), `packages/shared`, `packages/db`,
  `packages/api-client`, `packages/i18n`, `packages/ui`, `packages/config`,
  `packages/country-packs`.

### Shared config (`packages/config`)
- `tsconfig.base.json`: `strict`, `noUncheckedIndexedAccess`,
  `exactOptionalPropertyTypes`, `verbatimModuleSyntax`, ES2023 target, ESM.
- ESLint flat config: typescript-eslint (type-aware), import ordering,
  no default exports (except where frameworks require them), ban `console`
  in `apps/api` and `apps/worker` (use the logger).
- **SPDX header rule:** every `.ts`, `.tsx`, `.js`, `.mjs` source file must
  start with `// SPDX-License-Identifier: AGPL-3.0-only`. Implement as a small
  local ESLint rule with autofix.
- Prettier config; `.editorconfig`.
- Vitest base config.

### Licence check (`pnpm licenses:check`)
- Script in `packages/config/scripts/check-licenses.ts`, using
  `pnpm licenses list --json` (all workspaces, prod + dev).
- Allow list in `packages/config/licenses.json`, exactly as in
  `docs/licensing.md` (bundled list). An `exceptions` map (package → reason →
  ADR) that starts empty.
- `--mobile` mode: walks only the dependency tree of `apps/mobile` and the
  workspace packages it depends on, and **also rejects GPL, LGPL and AGPL**.
- Unknown or missing licences fail. Output: a readable table of violations.

### CI (GitHub Actions)
- `ci.yml` on push to `main` and on pull requests: checkout, set up Node via
  `.nvmrc`, enable Corepack, `pnpm install --frozen-lockfile`, then
  `lint`, `typecheck`, `test`, `licenses:check`, `licenses:check --mobile`.
  Use Turborepo caching (local cache in the Actions cache).
- `dco.yml`: fails if any commit in the push/PR lacks a `Signed-off-by:` line
  that matches the author. Small script in the repo, no third-party action
  required.
- `security.yml`: CodeQL (JavaScript/TypeScript) on push and weekly;
  OSV-Scanner on the lockfile; secret scanning is enabled in the repo settings
  (document this in `docs/operations/repo-settings.md`).
- Pin all third-party actions by full commit SHA.

### Repository hygiene
- `.gitignore` (node, turbo, next, expo, env files, coverage).
- `.env.example` at the root with the variables already named in the docs
  (`DEPLOYMENT_MODE`, `BILLING_ENABLED`, `USER_SIGNUP`, `CLUB_CREATION`,
  `DEFAULT_COUNTRY`, `DEV_AUTH`, `NODE_ENV`), dummy values, one-line
  comments.
- Renovate config (`renovate.json`): grouped updates, `minimumReleaseAge` of
  7 days, automerge only for patch updates of dev dependencies once CI is green.
- Commit message convention: Conventional Commits, checked in CI on PRs
  (local script, no hook required).
- `docs/operations/repo-settings.md`: branch protection for `main` (required
  checks), secret scanning, private vulnerability reporting.

## Privacy and security
- Lifecycle scripts disabled and a release-age delay reduce supply-chain risk.
- Actions pinned by SHA; `permissions:` set to the minimum in every workflow.

## Acceptance criteria
- [ ] Fresh clone: `pnpm install && pnpm lint && pnpm typecheck && pnpm test && pnpm licenses:check && pnpm licenses:check --mobile` all pass.
- [ ] Adding a file without the SPDX header fails `pnpm lint`; `pnpm lint --fix` adds it.
- [ ] A test fixture with a GPL-3.0 dependency fails `--mobile` but passes the normal check; an SSPL fixture fails both (unit tests for the checker).
- [ ] A commit without sign-off makes the DCO workflow fail (tested with the script's unit tests).
- [ ] CI green on `main`.
- [ ] `CLAUDE.md` commands section updated if any command name differs.
